# Qlark Free

Tiny floating macOS dictation app. On-device Qwen3-ASR 0.6B (4-bit MLX).
Click the floating button or press **Option-Space** to record, then stop to paste
into the focused field. No server is needed for transcription.

## Install / 安装

1. Unzip, quit older copies, then copy `Qlark.app` to `/Applications`.
2. In Finder choose **Go → Go to Folder** and enter
   `~/Library/Application Support/qlark/`. Create it if needed, then copy the
   enclosed `Models` folder into it. The resulting model folder must be
   `~/Library/Application Support/qlark/Models/aufklarer/Qwen3-ASR-0.6B-MLX-4bit/`.
   Keep all six files together. Preserve any unrelated models, recordings/results.
3. Open Qlark and confirm the standard first-open dialog if shown. This app is
   notarized; do not disable Gatekeeper. If unexpectedly blocked, verify the ZIP
   checksum and retain the error for the publisher before bypassing it.
4. Grant **Microphone** and **Accessibility**. If necessary, add
   `/Applications/Qlark.app` in **Privacy & Security → Accessibility**.
5. Wait for Ready. The lark appears at the right side of the menu bar;
   there is no Dock icon. Its menu includes Permissions and Quit.
6. Focus another app's field. **Option-Space** or click starts recording;
   press/click again to stop and paste once. Test Chinese and English, the
   animation, and clipboard restoration. If it says **Paste sent**, check the
   target before manually pasting to avoid a duplicate. **Done** means a text
   change was observed, not just that a paste event was sent.
